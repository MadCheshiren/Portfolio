# Product

## Register

brand

## Users
Recruiters, engineering leads, tech founders, and clients seeking a high-caliber Creative Developer, QA Specialist, and SysAdmin with a distinct aesthetic taste.

## Product Purpose
An elite personal developer portfolio showcasing technical precision in software engineering, QA testing, and visual novel game development through a minimalist, high-fashion editorial web design.

## Brand Personality
High-fashion editorial, precise, artistic, confident.
References: High-end print design, Swiss typography, minimalist editorial art galleries.

## Anti-references
Generic AI portfolio templates, colorful gradient text (`background-clip: text`), side-stripe accent borders, noisy dark mode defaults, rounded pill clutter, decorative glassmorphism.

## Design Principles
1. **Editorial Typography First**: Scale and weight contrast using Instrument Serif for headlines, Plus Jakarta Sans for body, and Geist Mono for metadata.
2. **Extreme Precision & Space**: Uncluttered white canvas with high contrast, crisp lines, and zero decorative clutter.
3. **Purposeful Kinetic Interactions**: 3D OptionWheel project selector, color-preserving Bayer dithered alcohol ink art, and scroll-driven statue slice assembly.

## Accessibility & Inclusion
WCAG AA contrast compliant text, high-legibility font sizes, smooth scroll triggers, and responsive layout for all viewports.
